# Эфир by maxon3r
## Меньше повторного набора — больше времени на главное

**Эфир** — программа автозамены для Windows: вы вводите короткий ключ, а она подставляет заранее подготовленный текст. Вместо длинного приветствия, объявления или ответа достаточно набрать несколько символов.

Например:

| Ключ | Текст замены |
|---|---|
| `пр` | Привет! Как дела? |
| `спс` | Спасибо большое! |
| `дата` | Сегодня {date}, время {time}. |

При стандартном режиме работы введите `пр` и нажмите пробел — ключ заменится на «Привет! Как дела?».

Программа подходит для повторяющихся сообщений, работы с объявлениями, ответов клиентам и игровых чатов, в которых разрешены подобные инструменты. Совместимость с конкретной игрой или приложением зависит от способа обработки ввода и их ограничений.

---

## Что удобно в Эфире

- **Быстрый ввод готовых текстов.** Сохраняйте часто используемые фразы и вызывайте их короткими ключами или отдельными горячими клавишами.
- **Раздельные наборы замен.** Радиоцентры LS, SF, LV и собственные профили позволяют использовать разные тексты для одних и тех же ключей.
- **Порядок в большой базе.** Поиск, группы, избранное, сортировка и массовые действия помогают работать с тысячами записей.
- **Подсказки поверх игры.** Компактный оверлей показывает подходящие ключи и начало текста, пока вы печатаете.
- **Динамические шаблоны.** Подставляйте дату, время и содержимое буфера обмена; задавайте место для курсора.
- **Перенос из Punto Switcher.** Поддерживаются импорт и экспорт файлов автозамен DAT, а также собственный JSON-формат.
- **Локальное хранение.** Для основной работы не нужен облачный аккаунт: база находится на вашем компьютере.
- **Резервные копии и сообщения об ошибках записи.** Программа создаёт копии перед предусмотренными массовыми и разрушительными действиями и сообщает, если данные не удалось сохранить.
- **Единое оформление.** Тёмный фиолетовый интерфейс, аккуратные статусы, диалоги и компактные подсказки.

> Эфир вставляет подготовленный вами текст. Это не генератор ответов и не сервис искусственного интеллекта. «Автораскладка» распределяет записи по группам на основе ключевых слов, а не переключает язык клавиатуры.

## 1. Установка и запуск

### Версия с исходным кодом

Это руководство описывает текущую Python-версию Эфира. Для неё нужен установленный Python; сам файл `main.py` не является EXE-программой.

1. Установите Python 3.10 или новее для Windows.
2. Сохраните файлы программы в постоянную папку.
3. Откройте командную строку в этой папке.
4. Установите зависимости:

```bat
py -3 -m pip install PyQt5 pynput pyperclip
```

5. Запустите программу:

```bat
py -3 main.py
```

Если в вашем комплекте есть `requirements.txt`, зависимости можно установить через него:

```bat
py -3 -m pip install -r requirements.txt
```

Если автор комплекта приложил `START.bat`, используйте его согласно инструкции к этому комплекту. Сам по себе `main.py` не создаёт такой файл.

Для обычного использования интернет не требуется. При первой установке зависимостей он может понадобиться.

### Первый запуск

По умолчанию выбран радиоцентр **LS**, а автозамена запускается **по кнопке**, не сразу при открытии окна. В новой базе есть несколько примеров: `пр`, `спс` и `дата`.

Повторный запуск программы открывает окно уже работающего экземпляра, а не создаёт вторую независимую копию.

## 2. Первая автозамена за минуту

1. Выберите нужный радиоцентр в нижней части левой панели.
2. Нажмите **«Новая замена»**.
3. В поле **«Ключ замены»** введите, например, `связь`.
4. В поле **«Текст замены»** напишите: «Спасибо за обращение! Скоро вернусь с ответом.»
5. Выберите группу или введите собственное название.
6. Убедитесь, что статус записи — **«Активна»**.
7. Нажмите **«Сохранить»**.
8. Нажмите **«Запустить»** в шапке программы.
9. Откройте Блокнот, введите `связь` и нажмите пробел.

Готово: вместо ключа появится сохранённый текст. Пробел после него сохраняется.

> Сначала проверяйте новые замены в Блокноте, а уже затем — в рабочих приложениях и чатах. Для первого знакомства удобнее режим «После пробела».

## 3. Главное окно и статусы

Интерфейс состоит из трёх основных областей:

- **Слева** — разделы «Все замены», «Избранное», «Группы», «История», «Настройки» и выбор радиоцентра.
- **В центре** — список записей или содержимое выбранного раздела.
- **Справа в разделах замен** — редактор выбранной записи.

В шапке находится общий переключатель:

- **«Остановлено» → «Запустить»** — автоматическая подстановка выключена.
- **«Работает» → «Остановить»** — автоматическая подстановка включена; кнопка остановки имеет красноватый оттенок и значок квадрата.

Остановить автозамену можно без закрытия программы. Редактировать базу при этом по-прежнему можно.

### Общий запуск и статус отдельной записи — разные вещи

Для срабатывания должны одновременно выполняться условия:

1. Эфир запущен в режиме **«Работает»**.
2. Выбран нужный радиоцентр.
3. У самой замены включён статус **«Вкл» / «Активна»**.

Над таблицей показаны четыре счётчика текущего радиоцентра:

- всего замен;
- включено, то есть **«в работе»**;
- в избранном;
- групп.

Эти значения описывают весь текущий радиоцентр и не превращаются в количество результатов поиска. Числа рядом с «Все замены» и «Избранное» в левой панели также относятся к текущему радиоцентру.

## 4. Раздел «Все замены»

Здесь находится база выбранного радиоцентра. В таблице показаны **ключ**, **текст**, **группа**, **статус** и кнопка **дополнительных действий**.

### Поиск и фильтры

Начните печатать в строке поиска: программа ищет по ключу, тексту и группе. Дополнительно можно выбрать конкретную группу.

Сортировка позволяет упорядочить записи:

- по ключу в прямом или обратном порядке;
- по группе в прямом или обратном порядке;
- по частоте использования — от частых к редким или наоборот.

Направление сортировки отмечается стрелкой в заголовке таблицы. Его можно менять через список сортировки или поддерживаемые заголовки столбцов. Сортировка по частоте связана со столбцом текста, поэтому для ясного выбора удобнее пользоваться списком.

Если ничего не найдено, проверьте одновременно строку поиска, фильтр группы и выбранный радиоцентр.

### Выбор записей

Нажмите строку, чтобы открыть запись в редакторе. Для нескольких записей используйте флажки, Ctrl или Shift при выделении. Флажок в заголовке выбирает записи текущего списка с учётом фильтров.

Внизу отображается количество выбранных записей и доступны действия над выделением.

## 5. Редактор замены

### Основные поля

**Ключ замены** — сокращение, которое вы будете набирать. Используйте запоминающиеся и достаточно уникальные ключи. В одном радиоцентре не должно быть двух одинаковых ключей; в разных радиоцентрах один ключ может вызывать разные тексты.

**Текст замены** — фраза или шаблон для вставки. Можно использовать несколько строк и переменные.

**Группа** — категория записи. Выберите существующую или напишите новое название: отдельная кнопка создания пустой группы для этого не требуется.

**Статус** — включает или выключает запись, не удаляя её.

**Избранное** — звезда в заголовке редактора и кнопка «Добавить в избранное» / «Убрать из избранного».

**Сохранить** — записывает изменения ключа, текста, группы и назначенной горячей клавиши. **Удалить** — удаляет запись после подтверждения.

Счётчики рядом с полями помогают следить за длиной. Числа `50` для ключа и `1000` для текста в текущем интерфейсе не означают автоматическое обрезание существующих записей.

> Сохраняйте изменения перед переходом к другой записи или сменой радиоцентра. Не рассчитывайте на автоматическое сохранение черновика текста. Статус и избранное у уже сохранённой записи, напротив, переключаются сразу и записываются с небольшой задержкой.

### «Дополнительные параметры»

Раскройте блок, чтобы увидеть:

- **Горячую клавишу конкретной замены.** Нажмите поле и введите сочетание. Esc или Backspace очищает назначение. После изменения нажмите «Сохранить». Сочетание вызывает запись без набора ключа, пока автозамена включена и активен её радиоцентр. Не назначайте сочетания, занятые запуском Эфира, оверлеем или другой активной записью.
- **Радиоцентр записи.** Показывает, к какому профилю она относится.
- **Количество использований.** Помогает понять, какие шаблоны действительно востребованы.
- **Кнопки переменных.** Вставляют выбранный маркер в текст в месте курсора.
- **Быстрый тест.** Введите точный сохранённый ключ текущего радиоцентра, чтобы посмотреть предварительный результат.
- **Копирование результата** и **очистку редактора**.

Быстрый тест — это предварительный просмотр, а не проверка глобального ввода в конкретной игре. Он использует сохранённую запись, обозначает переносы строк символом `↵`, а `{clipboard}` показывает как `[Буфер обмена]`. Отметка `[ОТКЛЮЧЕНА]` означает, что запись есть, но автоматическая подстановка для неё выключена.

## 6. Переменные и позиция курсора

### Динамические значения

| Маркер | Что подставляется при реальной замене |
|---|---|
| `{date}` | Текущая дата, например `15.03.2026` |
| `{time}` | Текущее время в формате `ЧЧ:ММ` |
| `{datetime}` | Дата и время с секундами: `ДД.ММ.ГГГГ ЧЧ:ММ:СС` |
| `{clipboard}` | Текст из буфера обмена |
| `[курсор]` | Место, куда нужно вернуть курсор после вставки |

Дата и время берутся с компьютера в момент срабатывания, а не при создании записи. Подсказка оверлея показывает текст шаблона, поэтому в ней могут быть видны сами маркеры.

Пример шаблона:

```text
Здравствуйте! Сегодня {date}. Ваш вопрос: [курсор]
```

Другой пример:

```text
Отправляю информацию: {clipboard}
```

Перед использованием второго шаблона скопируйте нужный текст. Не применяйте `{clipboard}` в публичном чате, если в буфере может оказаться конфиденциальная информация.

### Управление курсором

Режим выбирается в **«Настройки → Поведение → Позиция курсора»**.

**«Только [курсор]» — режим по умолчанию.** Также распознаётся английская запись `[cursor]`. Маркер удаляется из вставляемого текста, а курсор возвращается на его место.

Например:

```text
Привет, [курсор]!
```

После вставки получится `Привет, !`, а курсор окажется перед восклицательным знаком.

**«[курсор] и символ |».** Если текстового маркера нет, одиночная вертикальная черта тоже может задавать место курсора. Этот режим не включён по умолчанию: в объявлениях и префиксах вида `LS | текст` черта часто является обычным разделителем.

**«Отключено».** Программа не обрабатывает эти маркеры специально: они остаются частью текста.

Используйте одну метку позиции на шаблон. Позиционирование зависит от того, как целевое приложение обрабатывает перемещение курсора; сначала проверьте его в нужном поле ввода.

## 7. Раздел «Избранное»

Избранное — быстрый доступ к важным и часто используемым записям текущего радиоцентра.

Добавить запись можно звездой в редакторе, кнопкой в форме, через контекстное меню или действием над выделением. Повторное переключение позволяет убрать её из избранного.

Для массового действия логика такая:

- если не все выбранные записи уже избранные — добавить все выбранные;
- если все уже избранные — убрать все выбранные.

Избранное не включает отключённую запись автоматически и не создаёт отдельную копию. Это пометка той же записи. Счётчик слева показывает количество избранных замен в активном радиоцентре.

## 8. Контекстное меню и массовые действия

Нажмите **правой кнопкой мыши** по записи или кнопку **•••** в её строке.

Для одной записи доступны:

- **Редактировать** — открыть её в редакторе.
- **Создать дубликат** — подготовить копию в редакторе с новым ключом; для добавления в базу её нужно сохранить.
- **Копировать → Ключ / Текст замены** — скопировать нужное содержимое.
- **Добавить в избранное / Убрать из избранного**.
- **Включить / Выключить замену**.
- **Сменить группу…**
- **Другой радиоцентр → Перенести… / Создать копии…**
- **Удалить замену…** — с подтверждением.

При выборе нескольких строк меню работает с выделением. Можно копировать ключи или тексты, менять статус и избранное, назначать группу, переносить, клонировать и удалять несколько записей сразу.

Кнопка **••• в нижней панели** открывает меню рядом с собой и действует на выделенные записи, даже если они сейчас прокручены за пределы видимой части таблицы. Кнопка «Редактировать» при множественном выделении открывает одну запись, а не общий редактор всех текстов.

Перед массовыми изменениями смотрите на счётчик выделения. Поиск и фильтры меняют состав текущего списка.

## 9. Радиоцентры: отдельные наборы замен

Радиоцентр — это профиль. По умолчанию есть **LS**, **SF** и **LV**, но названия можно использовать и для других задач: «Работа», «Личное», «Поддержка».

Нажмите блок радиоцентра внизу слева, чтобы:

- переключить активный набор;
- увидеть количество записей в профилях;
- создать новый радиоцентр;
- удалить ненужный профиль через предусмотренное действие.

Автозамена и подсказки используют только включённые записи активного радиоцентра. Переключение профиля не переносит записи само по себе.

### Перенос и создание копий

**Перенести** — убрать выбранные записи из исходного радиоцентра и добавить в целевой. Если там уже есть такие ключи, программа предложит заменить совпадения, пропустить их или отменить действие.

**Создать копии** — оставить исходные записи и добавить копии в другой радиоцентр. Если ключ занят, к новому ключу добавляется числовой суффикс, например `_2`.

### Автоматическая замена префикса

Если текст начинается с распознанного названия радиоцентра и разделителя `|`, при переносе, создании копий в другом профиле и импорте начальный префикс адаптируется к целевому радиоцентру.

Например, при переносе из LS в LV:

```text
LS | Добро пожаловать!
```

станет:

```text
LV | Добро пожаловать!
```

Обычный текст без такого начального префикса не получает его автоматически. Упоминания радиоцентров внутри сообщения не заменяются глобально.

## 10. Раздел «Группы» и автораскладка

Группы — категории внутри текущего радиоцентра. Они формируются из записей: чтобы создать новую, достаточно указать её название при сохранении замены или массовой смене группы.

Раздел показывает список групп и количество записей в каждой. Выберите группу, чтобы:

- **переименовать** её;
- **объединить** с другой — все записи перейдут в выбранную категорию;
- **удалить** с выбором дальнейшего действия над записями.

При удалении читайте подтверждение: можно переместить записи в **«Общие»** либо удалить их вместе с группой. У группы «Общие» есть особенность: перенос её записей обратно в «Общие» не меняет их категорию.

### Кнопка «Автораскладка»

Это **разовое действие по нажатию**, а не постоянный переключатель.

Программа проверяет тексты текущего радиоцентра и распределяет их по встроенным категориям на основе ключевых слов: например, «Транспорт», «Недвижимость», «Бизнес», «Медицина», «Полиция», «СМИ» и другим. Если подходящих признаков нет, используется «Общие».

Перед изменениями появляется подтверждение. Автораскладка может заменить ваши ручные категории, поэтому перед большой реорганизацией полезно сделать JSON-экспорт. Результат можно скорректировать вручную.

## 11. Работа с эмодзи

Кнопка **«Эмодзи…»** открывает обработку текстов:

1. добавить введённый символ или сочетание в начало;
2. добавить в конец;
3. удалить распознаваемые эмодзи из текста.

Если есть выделение, действие применяется к выбранным записям. Если ничего не выбрано, программа запрашивает подтверждение; фактический набор в текущей версии определяется текущим списком с учётом поиска, группы и режима избранного. Чтобы обработать весь радиоцентр, откройте «Все замены» и снимите фильтры.

Проверьте результат на нескольких записях, прежде чем обрабатывать большую базу. Сложные составные эмодзи, модификаторы и комбинированные последовательности могут потребовать ручной проверки после удаления.

## 12. Игровой оверлей

Оверлей — компактное окно подсказок поверх игры или другого приложения. Он помогает вспомнить ключ и увидеть начало соответствующего текста.

### Как включить

1. В **«Настройки → Игровой режим»** разрешите оверлей и сохраните настройки.
2. Запустите автозамену.
3. Нажмите **Alt+2** — стандартную клавишу переключения оверлея.
4. Начните вводить ключ в поле игры или приложения.

По умолчанию подсказки появляются от двух символов. Например, при вводе `па` будут показаны включённые ключи текущего радиоцентра, начинающиеся на `па`.

### Что показывает оверлей

- текущий распознанный запрос;
- подходящие ключи и начало их текстов;
- число показанных вариантов;
- зелёную отметку точного совпадения.

Точное совпадение ставится выше более длинных продолжений. После выполнения замены, отсутствия подходящих вариантов или периода бездействия окно возвращается к компактной плашке.

Оверлей не является отдельным полем ввода: печатать нужно в игре или приложении. Он не предназначен для перехвата фокуса или кликов. Номера строк — обозначения вариантов, а не команды вставки цифрами. Выбор строк стрелками или мышью в текущей версии не предусмотрен: допишите ключ и используйте выбранный режим срабатывания либо назначенную горячую клавишу записи.

Если совпадений нет, оверлей не показывает произвольный введённый текст. Это, однако, не заменяет осторожность при использовании глобального инструмента ввода.

### Настройка показа

В игровом разделе настроек доступны:

| Параметр | Назначение | По умолчанию |
|---|---|---|
| Оверлей | Разрешить или запретить подсказки | Включён |
| Горячая клавиша | Показать или скрыть оверлей во время работы | `Alt+2` |
| Положение | Один из четырёх углов экрана | Справа сверху |
| Прозрачность | Больший процент делает окно менее прозрачным | 92% |
| Количество вариантов | От 1 до 8 подсказок | 5 |
| Минимум символов | Длина запроса до появления подсказок | 2 |
| Сворачивать через | Возврат к компактному виду без обновлений ввода | 5000 мс |
| Сброс буфера | Пауза, после которой следующий ввод начинает новый буфер распознавания | 3000 мс |
| Отступ от края | Расстояние до края экрана | 24 px |

**1000 мс = 1 секунда.** Сброс буфера не удаляет напечатанное из чата: очищается только внутренний буфер Эфира. Этот параметр влияет и на распознавание замен, поэтому увеличьте его, если часто делаете длинные паузы посреди ключа.

На экране с небольшой доступной высотой оверлей ограничивает число видимых строк, чтобы окно не выходило за его границы. В текущей реализации размещение рассчитывается относительно основного экрана Windows.

Для игр рекомендуется **оконный или безрамочный режим**. Эксклюзивный полноэкранный режим и защитные механизмы игры могут скрывать или блокировать сторонние окна. Не обходите ограничения игры и проверяйте её правила.

## 13. Раздел «История»

История показывает последние выполненные замены:

- дату и время;
- ключ;
- радиоцентр, к которому относилась запись.

Новые события находятся сверху. Журнал общий для радиоцентров, поэтому профиль указан в отдельном столбце.

По умолчанию хранится **100 последних событий**. В интерфейсе можно включить или выключить ведение истории; отдельного регулятора её размера на странице настроек сейчас нет.

Кнопка **«Очистить историю»** удаляет журнал после подтверждения, но не удаляет сами замены. Отключение истории прекращает добавление новых событий, а не стирает предыдущие автоматически. История не является системой отмены и не хранит полный текст каждого набранного сообщения.

## 14. Настройки

Страница содержит четыре вкладки. Обычные изменения настроек вступают в силу после нажатия **«Сохранить»**.

### «Основные»

- **Запуск автозамены:** сразу при открытии программы или вручную по кнопке.
- **Горячая клавиша:** общее включение и выключение автозамены; по умолчанию `Ctrl+Alt+F10`.
- **Режим срабатывания:**
  - **После пробела** — введите ключ и нажмите пробел; после вставки пробел сохраняется.
  - **После Enter** — введите ключ и нажмите Enter. В Windows при найденной замене исходный Enter перехватывается, а после вставки программа обычно отправляет Enter сама. В чате это может сразу отправить сообщение. При шаблоне с обрабатываемой меткой курсора завершающий Enter не отправляется автоматически.
  - **Мгновенно** — запись подставляется сразу после полного совпадения ключа. Короткий ключ может сработать раньше, чем вы допечатаете более длинный: выбирайте этот режим осознанно.
  - **После пунктуации** — подстановка по символам `. , ! ? ; :`; введённый знак сохраняется после текста.

Распознавание учитывает границу ключа: окончание обычного слова не должно само по себе превращаться в чужое сокращение. Для предсказуемой работы начинайте ключ отдельно от предыдущего слова.

### «Игровой режим»

Содержит включение оверлея, его сочетание клавиш, положение, прозрачность, число вариантов и тайминги. Подробности — в разделе 12.

### «Поведение»

- **Регистр:** считать `Пр` и `пр` разными или одинаковыми при распознавании. По умолчанию регистр не учитывается. При таком режиме лучше не создавать ключи, различающиеся только регистром.
- **Позиция курсора:** только `[курсор]`, текстовый маркер вместе с `|` либо полное отключение обработки меток.

### «Система»

- **История замен:** сохранять новые события или не вести журнал.
- **При закрытии окна:** свернуть программу в трей или полностью закрыть.
- **Автозапуск:** открывать Эфир вместе с Windows.

Автозапуск Windows и автоматическое включение замен — разные настройки. Можно запускать программу при входе в систему, но оставлять автозамену остановленной до нажатия кнопки.

Если используете исходники и включили автозапуск, не переносите папку программы и интерпретатор Python без обновления настройки.

### Кнопки внизу

- **«Сохранить»** — применить и записать настройки.
- **«Отменить изменения»** — вернуть значения, сохранённые до текущего редактирования.
- **«Сбросить к стандартным»** — подставить стандартные настройки; затем нужно нажать «Сохранить». Это не кнопка удаления базы.

При переходе из настроек в другой раздел с несохранёнными изменениями программа предлагает сохранить их, отказаться от них или остаться на странице.

### «Опасная зона»

Здесь находятся отдельные действия:

- **Очистить всю базу** — удалить замены во всех радиоцентрах.
- **Очистить замены** — удалить записи только выбранного радиоцентра, оставив профиль.
- **Удалить радиоцентр** — удалить выбранный профиль и относящиеся к нему записи. Последний оставшийся радиоцентр удалить нельзя.

Эти действия выполняются отдельно от обычного редактирования настроек и требуют подтверждения. Не считайте кнопку «Отменить изменения» способом отменить уже выполненную очистку.

## 15. Импорт и экспорт

### Какие файлы поддерживаются

| Формат | Для чего подходит |
|---|---|
| JSON Эфира | Перенос замен с их свойствами; полный экспорт состояния программы |
| Punto Switcher DAT | Обмен парами «ключ → текст» с поддерживаемым бинарным форматом автозамен |

### Импорт

1. Нажмите **«Импорт»**.
2. Выберите файл `.json` или `.dat`.
3. Дождитесь чтения файла.
4. Если в JSON есть одинаковые ключи из разных радиоцентров, выберите исходный радиоцентр.
5. Укажите, в какой существующий радиоцентр добавить записи. По умолчанию предлагается активный.
6. Если есть совпадающие ключи, выберите: заменить существующие, пропустить совпадения или отменить импорт.

Префиксы вида `LS | ` в начале текста адаптируются к выбранному профилю назначения. Для записей без специальной группы или с общей импортной категорией программа может определить группу по тексту; это не гарантирует сохранения категории «Общие» у каждой импортированной записи.

**Важно:** импорт JSON через кнопку добавляет записи в выбранный радиоцентр. Он не является полным восстановлением настроек, истории и структуры всех профилей, даже если эти данные присутствуют в экспортированном JSON.

### Экспорт JSON

Выгружает **всё текущее состояние базы**: замены всех радиоцентров, настройки, историю и свойства записей, включая группы, избранное, статусы, счётчики и назначения горячих клавиш. Выделение строк и фильтр поиска не ограничивают такой экспорт.

Это удобный вариант для архивной копии перед обновлением, реорганизацией или переносом программы.

### Экспорт DAT

Выгружает пары **«ключ → текст» только активного радиоцентра**, а не только выделенных строк. Записи с пустым текстом в DAT не записываются.

DAT не сохраняет группы, избранное, счётчики, назначения горячих клавиш, профили и состояния включения. Даже отключённая в Эфире запись с непустым текстом может попасть в DAT как обычная пара: при переносе проверяйте результат в другой программе.

Маркеры шаблонов передаются как текст; поддержка их выполнения в другом приложении зависит от самого приложения.

### Совместимость с Punto Switcher

Поддерживается бинарный файл пользовательских автозамен `replace.dat` с сигнатурой **PSRF**. Не любой файл с расширением `.dat` имеет такой формат. Сам файл Punto Switcher в комплект Эфира автоматически не добавляется — его выбирает пользователь.

## 16. Данные, сохранение и резервные копии

### Где находятся файлы

```text
%APPDATA%\Efir\binder_data.json
%APPDATA%\Efir\backups\
%APPDATA%\Efir\efir.log
```

- `binder_data.json` — основная база, настройки и история.
- `backups` — автоматические резервные копии.
- `efir.log` — диагностический журнал.

Чтобы открыть папку, нажмите **Win+R**, введите `%APPDATA%\Efir` и подтвердите.

При обычной замене файла `main.py` база из этой папки не переносится в папку исходников. Тем не менее перед обновлением рекомендуется сделать отдельный JSON-экспорт.

### Как сохраняются изменения

Редактирование текста и явные массовые/разрушительные действия записываются с проверкой результата. Частые переключения вроде избранного и включения записи применяются сразу, а запись на диск выполняется с небольшой задержкой.

Если сохранение не удалось, программа показывает предупреждение и кнопку **«Повторить сохранение»**. Не игнорируйте такую ошибку и не закрывайте программу, пока важные изменения остаются только в памяти.

- Если не сохранилось отдельное подтверждённое действие, устраните причину и повторите это действие.
- Для черновика снова нажмите **«Сохранить»** в редакторе.
- Для уже применённых изменений, ожидающих записи, используйте **«Повторить сохранение»**.

Проверьте свободное место, права доступа к папке и ограничения антивируса. Кнопка повтора сохраняет текущее состояние, а не автоматически выполняет заново отменённый перенос или удаление.

### Автоматические копии

Перед предусмотренными массовыми и разрушительными действиями создаётся копия существующей базы. Хранятся последние **20 копий**. Это не копия на каждое нажатие клавиши, не облачное хранение и не универсальная кнопка «Отменить».

Если основной файл не читается, при запуске программа пытается восстановить данные из подходящей резервной копии и сообщает о результате. Это не означает автоматического отката корректного, но нежелательного удаления.

### Полное ручное восстановление

1. Полностью закройте Эфир через меню трея.
2. Скопируйте текущую папку `%APPDATA%\Efir` в безопасное место.
3. Выберите нужную копию `binder_*.json` в `backups` либо полный JSON-экспорт Эфира.
4. Скопируйте выбранный файл в `%APPDATA%\Efir` под именем `binder_data.json`, заменив основной файл.
5. Запустите программу и проверьте профили, записи и настройки.

Такое восстановление заменяет текущее состояние целиком. Для добавления только отдельных записей используйте обычный импорт, а не замену файла базы.

### Конфиденциальность

База, экспорт и резервные копии — обычные файлы без встроенного шифрования. Человек с доступом к ним может прочитать тексты. Не используйте Эфир как хранилище паролей, платёжных реквизитов или одноразовых кодов. Перед отправкой базы или журнала поддержки проверьте их содержимое.

## 17. Трей, закрытие и перезапуск

Если выбрано **«При закрытии окна → В трей»**, крестик скрывает окно, но не обязательно останавливает автозамену.

Нажмите правой кнопкой на значок Эфира возле часов Windows. В меню доступны:

- **Открыть Эфир**;
- **Запустить / Остановить**;
- **Перезапустить**;
- **Полностью выйти**.

Двойной щелчок по значку открывает главное окно. Чтобы гарантированно завершить работу приложения, используйте **«Полностью выйти»**.

## 18. Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+F10` | Запустить или остановить автозамену; можно изменить в настройках |
| `Alt+2` | Показать или скрыть оверлей, когда автозамена работает; можно изменить |
| `Ctrl+N` | Создать новую замену в главном окне |
| `Ctrl+F` | Перейти к строке поиска в главном окне |
| `Ctrl+S` | Сохранить запись из редактора; при пустом поле ключа — записать текущее состояние |

Сочетания главного окна зависят от текущего фокуса: редакторы текста и другие поля могут обрабатывать стандартные команды самостоятельно. Глобальные сочетания могут конфликтовать с клавишами игры или других программ — выбирайте свободные комбинации.

## 19. Частые вопросы и ограничения

### Замена не срабатывает

Проверьте:

1. В шапке написано **«Работает»**.
2. Выбран нужный радиоцентр.
3. У записи стоит **«Вкл»**, а изменения сохранены.
4. Вы используете правильный режим: пробел, Enter, пунктуацию или мгновенный ввод.
5. Нет расхождения по регистру и раскладке клавиатуры.
6. Посреди ключа не было паузы дольше времени сброса внутреннего буфера.
7. Замена работает в обычном Блокноте.

Если игра или другое целевое приложение запущено от администратора, Windows может блокировать вставку из программы с меньшими правами. При необходимости запускайте доверенную копию Эфира с соответствующими правами; постоянно запускать всё от администратора без причины не нужно.

Отдельные защищённые поля, приложения и игры могут не принимать синтетический ввод. Совместимость с каждым приложением не гарантируется.

### Программа работает, но оверлей не виден

Проверьте разрешение оверлея в настройках, нажмите его горячую клавишу и попробуйте оконный или безрамочный режим игры. Убедитесь, что ищете подсказку на основном экране и в выбранном углу.

Если плашка видна, но списка нет, проверьте минимальную длину запроса, наличие включённых ключей с таким началом и активный радиоцентр.

### Напечатанное не совпадает с подсказкой

Оверлей не читает содержимое поля из игры: он строит подсказки по собственному буферу клавиатурного ввода. Перемещение курсора, вставка через другое приложение и игровые особенности могут нарушать соответствие. Начните новый ключ с пустого поля и проверьте сценарий в Блокноте.

### Enter сразу отправляет сообщение

Это ожидаемый риск режима «После Enter»: после вставки программа обычно повторяет Enter. Для ручной проверки текста перед отправкой выберите **«После пробела»**.

### После переноса поменялось `LS |` на `LV |`

Это предусмотренная адаптация начального префикса под профиль назначения. Она действует также при импорте и создании копий в другом радиоцентре.

### Звезда есть, а замена не срабатывает

Избранное — пометка для удобства. Она не включает отключённую запись и не переключает радиоцентр.

### Почему удалённая запись осталась в истории

История — отдельный журнал прошедших событий. Удаление записи не обязано удалять сведения о её прошлых срабатываниях. Журнал очищается отдельно.

### Почему импорт JSON не вернул все настройки

Кнопка импорта загружает замены в выбранный радиоцентр. Полное восстановление выполняется заменой `binder_data.json` при полностью закрытой программе — см. раздел 16.

### Можно ли использовать Эфир в любой игре

Нет универсальной гарантии. Проверьте правила сервера и игры, разрешение на автозамену и оверлеи, а также совместимость ввода. Программа не предназначена для обхода античита или запретов сервиса.

### Это макросы или автоматическое прохождение игры

Нет. Основная задача Эфира — подстановка сохранённых текстов. Он не управляет игровым персонажем и не выполняет игровые сценарии.

## 20. Как пользоваться удобно и безопасно

- Начните с небольшого набора действительно нужных фраз.
- Для ключей используйте узнаваемые сокращения, которые редко встречаются в обычном тексте.
- Разделяйте контексты радиоцентрами, а темы — группами.
- Добавляйте основные записи в избранное.
- Для больших правок сначала экспортируйте JSON, затем проверяйте действие на нескольких записях.
- Перед обработкой всей базы снимайте фильтры и проверяйте выделение.
- Не игнорируйте предупреждения о несохранённых данных.
- Не храните в шаблонах секреты и проверяйте буфер обмена перед использованием `{clipboard}`.
- Для чатов, где сообщение нельзя отправить случайно, выбирайте режим «После пробела».
- Проверяйте результат в нужном приложении: предварительный просмотр в редакторе не заменяет такую проверку.

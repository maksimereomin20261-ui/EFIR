# Эфир — Windows

Исходная программа находится в `app/main.py`. Рабочие автозамены и настройки остаются в `%APPDATA%\Efir`, отдельно от файлов приложения. Не добавляйте эту папку, резервные копии, журналы или личные замены в репозиторий.

## Сборка и обновления

GitHub Actions собирает тестовые `Efir_Setup.exe` и `Efir-App.zip`. Это не выпуск обновления. Установщик получает пакет последнего публичного GitHub Release, проверяя его размер и SHA-256, затем запускает приложение. После создания релиза установщик можно давать пользователям; для будущего обновления надо собрать новый пакет и отдельно опубликовать его под именем `Efir-App.zip`. Без релиза первичная установка не работает.

Старые версии и повреждённые папки пока сохраняются, чтобы не потерять возможные файлы пользователя. Проверка процесса не является проверкой готовности приложения. Автоматический откат после падения ещё не реализован. Изменения самого загрузчика пока требуют повторного запуска нового установщика.

## Проверка

В автоматической сборке тестируются сохранение данных, защита загрузчика, создание пакета и появление окна. Необходимо отдельно проверить на настоящем Windows 11 установку, обновление, автозапуск, повторный запуск, работу хоткеев, трея и оверлея. EXE без цифровой подписи может вызывать предупреждения Windows.

Справка по функциям приложения — в `app/README.md`. В ней описан исходный запуск, а не установщик.
